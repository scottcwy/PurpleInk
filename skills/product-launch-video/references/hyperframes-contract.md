# Hyperframes Compiler Boundary

The skill does not author Hyperframes compositions. Return `LaunchVideoPlanV1` JSON and stop.

The deterministic compiler owns all HTML, CSS, JavaScript, Hyperframes attributes, root compositions, assets, responsive geometry, and quality gates. It accepts only versioned template capability IDs. Preview and final rendering consume the same immutable `CompositionBundleV1`; no model runs between them.

Required downstream gates are Hyperframes `lint`, `validate`, `inspect --json`, media probing, evidence-reference validation, and non-blank sampled frames. A plan is not permission to bypass any compiler or quality gate.
