采用前后端分离的双包结构：根目录为 Next.js 前端应用（src/app 使用 App Router 分组路由 `(auth)`/`(marketing)`/`(public)`/`products/(app)`），server/ 为独立的 Node/TypeScript 渲染 Worker（purpleink-server），两者通过 pnpm workspace 管理。
- 请求路径：浏览器统一访问 `/api/*`，由 next.config.ts 的 `rewrites` 转发至 BACKEND_ORIGIN（默认 http://localhost:8787）指向 server/src/index.ts；生产环境通过 Caddy 反向代理单域名部署，worker 不对外暴露。
- 前端分层：`src/app` 为页面与 API Route，`src/components` 为 UI 组件库（含 demo.test 模式），`src/features` 按业务域拆分（ai、auth、billing、canvas、director、render、audio、projects 等），`src/lib` 存放跨领域基础设施（db、queue、storage、tts、workflow 等）。
- 后端分层：server/src 下按职责划分 adapter（采集适配器）、capture（Playwright/Mock 浏览器驱动）、compose（章节/项目/渲染管线）、server（API/内部认证/Job Runner/Store）、tts（ListenHub 语音合成）、lib（日志/错误处理）。
- 数据库：Drizzle ORM + PostgreSQL，schema 位于 src/lib/db/schema/index.ts，迁移输出至 src/lib/db/migrations/pg。
- 构建与运行：pnpm monorepo，Node ≥22.11，@earendil-works/pi-ai 与 pi-agent-core 通过 serverExternalPackages 外部化以避免 Turbopack 动态 require 失败。
