项目采用前后端分离的双包结构：根目录为 Next.js 应用（src/app 路由、src/components UI 组件、src/features 业务域），server/ 是独立的 Node 渲染服务（purpleink-server）。Next.config.ts 通过 rewrites 将 /api/engine/* 转发到 BACKEND_ORIGIN（默认 localhost:8787），生产环境由 Caddy 反向代理统一暴露单域名。features/ 按领域划分 ai、auth、billing、canvas、director、render、audio 等子模块，每个模块内自包含 domain、repository、client adapter 及测试文件；lib/ 提供跨域共享的基础设施（db、queue、storage、tts、workflow 等）。server/src 内部再分 adapter（页面采集）、capture（Playwright/Mock 驱动）、compose（章节/项目/模板编排）、tts（语音合成）、server（API + Job Runner + Job Store）等层，依赖方向单向：adapter → capture → compose → tts → server。数据库使用 Drizzle ORM + Postgres，构建产物通过 .next 与 server/out 隔离，CI 通过 vitest.pg.config.ts 运行集成测试。
