- 每个功能域在 src/features/<domain>/ 下按能力拆分为多个文件（如 ai/ 下有 adapter、config、provider-*、workspace-concurrency-* 等），测试文件与源码同名 .test.ts 并列放置
- 环境变量通过 server/src/lib/load-env.ts 统一加载，优先读取 server/.env 再叠加仓库根 .env.local，避免硬编码配置
- API 路由遵循 Next.js App Router 约定，放在 src/app/api/<resource>/route.ts，内部 API 通过 server/src/server/internal-api.ts 暴露给前端
- 所有用户输入与外部数据使用 Zod v4 schema 进行运行时校验，错误通过 provider-request-error.ts 等专用错误类型向上抛出
- 日志输出统一通过 server/src/lib/logger.ts 封装，区分 info/warn/error 级别，生产环境移除 console.log 仅保留 error/warn
