该模块是一个最小化的 Caddy 反向代理容器：
- `Dockerfile` 以 `caddy:2.10-alpine` 为基础镜像，仅拷贝 `Caddyfile` 和 `entrypoint.sh`，并将后者设为 ENTRYPOINT。
- `entrypoint.sh` 在容器启动时从 `/run/secrets/basic_auth_credentials`（由 Docker Compose `secrets:` 挂载）解析单行 `<用户名> <bcrypt哈希>`，导出为 `CVC_BASIC_AUTH_USER`、`CVC_BASIC_AUTH_HASH` 环境变量；若文件缺失则直接退出，拒绝无认证启动。同时暴露 `CVC_ALLOWED_CIDRS` 环境变量（默认 `0.0.0.0/0 ::/0`）用于控制允许的客户端 CIDR。
- `Caddyfile` 是实际的代理配置（二进制文件未读取），由 `entrypoint.sh` 通过 `--config /etc/caddy/Caddyfile --adapter caddyfile` 加载。
- `secrets/` 目录存放凭据模板与实际值，实际凭据文件通过 `.gitignore` 排除提交，仅随 Compose secrets 在运行期注入。
依赖方向单一：entrypoint → Caddy，凭据来源为 Compose secrets，不依赖任何外部服务。
