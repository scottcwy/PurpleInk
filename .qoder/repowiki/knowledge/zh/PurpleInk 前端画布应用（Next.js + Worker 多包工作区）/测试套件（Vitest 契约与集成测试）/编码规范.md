- 每个测试文件以单个 describe 块组织，内部用 it 描述具体断言，不使用嵌套 describe。
- 对外部依赖（fetch、进程执行、第三方模块）统一通过 vi.fn 或 vi.mock 注入 mock，避免真实网络或文件系统调用。
- 契约类测试通过 readFile 读取源码或 .env.example 后用正则匹配断言结构，而非解析 AST。
- 临时文件通过 mkdtemp + tmpdir 创建，并在 afterEach 中统一 rm 清理。
- UI 测试统一使用 react-dom/server 的 renderToStaticMarkup 生成字符串后做 toContain / toMatch 断言。
