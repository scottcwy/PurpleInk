- 顶层 package.json 定义所有跨子包脚本（dev:all、db:migrate、verify:*、test:pg），pnpm-workspace.yaml 将根目录与 server/ 纳入同一工作区，共享依赖与命令。
- Next.js 作为唯一对外入口，通过 next.config.ts 的 rewrites 将 /api/engine/* 透明转发到内网 worker（BACKEND_ORIGIN），浏览器无跨域且生产单域名。
- Dockerfile 采用多阶段构建：deps → build → migrate（保留 devDependencies 供 tsx/drizzle-kit）→ runtime（非 root pwuser、Chromium、CJK 字体），docker-compose.prod.yml 按顺序启动 postgres → migrate → bootstrap-credentials → seed-demo-account → next → reverse-proxy，worker 仅内网访问。
- drizzle.config.ts 指定 PostgreSQL 方言与 schema/migrations 路径，vitest.config.ts 与 vitest.pg.config.ts 分别隔离普通测试与 .pg.test.ts 集成测试。
- 测试套件（tests/）与验证脚本（scripts/）通过统一的 pnpm test/test:pg 入口驱动，覆盖路由契约、TTS 管线、组件渲染与环境变量隔离。
