- CLI 参数统一采用 `--key value` 双段形式解析，白名单校验未知 flag 并在缺失必填参数时报错退出。
- 脚本入口通过 `if (process.argv[1] === fileURLToPath(import.meta.url))` 判断是否直接执行，避免被 import 时触发副作用。
- 在 Next runtime 之外访问业务模块前，先用 `createRequire` 拦截 `server-only` bare specifier 重定向到 `server-only-stub.js`，再 dynamic import 业务代码。
- 错误处理统一输出结构化 JSON 到 stderr（包含 `status`、`code` 字段）并设置 `process.exitCode`，成功路径输出纯文本摘要，确保可被容器编排解析。
- 敏感变量（如 `CVC_CREDENTIAL_MASTER_KEY`、`GEMINI_API_KEY`）仅检查存在性，绝不打印或记录其值，必要时在处理后清空 `process.env` 中的临时副本。
