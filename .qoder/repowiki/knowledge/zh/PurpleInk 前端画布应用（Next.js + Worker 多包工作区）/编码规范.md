- 所有跨环境脚本集中在 scripts/ 下，通过 pnpm 脚本别名暴露，子包不重复定义相同命令
- 数据库 schema 与迁移由 drizzle-kit 统一管理，schema 位于 src/lib/db/schema/index.ts，迁移输出至 src/lib/db/migrations/pg
- 测试文件按功能分目录，Postgres 集成测试使用 .pg.test.ts 后缀并由 vitest.pg.config.ts 单独包含
- 环境变量通过 docker-compose 注入，敏感值使用 secrets 或一次性 bootstrap-credentials 任务写入加密存储，运行时只读 DB
- Next.js 与 worker 之间仅通过 /api/engine/* 反向代理通信，禁止浏览器直连 worker
