- features 目录下每个业务域按 domain.ts、repository.ts、service.ts、*.test.ts 分层组织，测试文件与源码同名并列放置。
- API 路由遵循 Next.js App Router 约定，放在 src/app/api/<domain>/[...]/route.ts 或 route.ts，通过 rewrites 统一转发到后端 worker。
- 组件文件采用 .tsx 命名并配套 .demo.tsx 演示文件与可选 .test.ts 单元测试，UI 基础组件集中在 src/components/ui。
- 环境变量通过 .env.example 与 config/tts.env.example 声明，运行时加载使用 lib/config 或 server/src/lib/load-env。
- 错误处理统一通过自定义 Error 类（如 provider-unavailable-error.ts、unauthenticated-error.ts）并在 API 层转换为标准响应。
