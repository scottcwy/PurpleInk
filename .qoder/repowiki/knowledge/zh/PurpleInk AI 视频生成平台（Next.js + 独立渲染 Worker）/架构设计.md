项目采用前后端分离的双进程架构：
- 前端为 Next.js 16 App Router 应用（src/app），按路由分组 (auth)、(marketing)、(public)、products/(app) 等；UI 组件集中在 src/components/ui 与 src/components/marketing，业务功能以 features/* 目录划分（ai、auth、billing、canvas、director、render、audio、artifacts、credentials、navigation、projects、routing）。
- 后端为独立 Node/TypeScript 服务（server/src），包含 adapter（页面采集）、capture（Playwright/Mock 驱动）、compose（章节/项目/模板编排）、tts（语音合成）、server（API/Job Runner/Store）等子模块，通过 next.config.ts 的 rewrites 将 /api/engine/* 转发到 BACKEND_ORIGIN（默认 http://localhost:8787）。
- 数据库使用 Drizzle ORM + Postgres（drizzle.config.ts），迁移与种子脚本位于 scripts/setup 与 scripts/migration。
- 测试统一用 Vitest（vitest.config.ts），Postgres 相关用例通过 vitest.pg.config.ts 运行；E2E 使用 Playwright（.playwright-cli 下大量截图与 YAML 记录）。
- 部署通过 Dockerfile（根目录）与 docker-compose.dev.yml/prod.yml，反向代理由 Caddy（deploy/reverse-proxy/Caddyfile）提供 Basic Auth 与 HTTPS。
- 依赖 @earendil-works/pi-ai 与 pi-agent-core 作为 AI 适配器层，并通过 patches/@earendil-works__pi-ai.patch 修补上游行为。
