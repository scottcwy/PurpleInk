- 每个 features 目录通过 index.ts 统一公开导出，跨域复用现有导出，禁止为同一职责创建平行 wrapper 或纯 re-export 壳。
- src/app 仅做参数解析、组合与响应映射，不放置 SQL、渲染参数或复杂业务状态机；复杂逻辑下沉至 features/ 与 lib/。
- UI 组件统一从 components/ui/ 引入，禁止在页面内本地拼装 Button/Card/Badge/Sidebar/Tabs 等重复实现，视觉真值以 docs/designs/canvas.pen 为准。
- 错误处理遵循 AGENTS.md §6：不向用户暴露 provider 原始错误、raw assistant delta、tool 参数或 prompt，只返回类别文案与 error.digest。
- 凭据与密钥仅存加密内容，master key 仅从 server-only 环境读取，客户端不得解析 provider credential，设置类 API 必须先验证再保存且失败返回 422。
- 所有可寻址表面（页面、API、元数据路由）变更必须先更新 docs/conventions/routing.md，再以该文件为唯一真值同步代码。
