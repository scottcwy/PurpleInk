项目采用前后端分离的双进程架构：
- 前端根目录为 Next.js 16 App Router 应用，src/app 下按路由组 (auth)/(marketing)/(public) 组织页面，src/features 按业务域拆分（ai、artifacts、audio、auth、billing、canvas、director、render、routing 等），src/components/ui 提供原子化 UI 组件。
- 后端位于 server/ 子包（purpleink-server），独立 package.json 与 tsconfig，通过 Playwright 驱动浏览器采集、HyperFrames 管线渲染、TTS 合成，由 src/index.ts 暴露 HTTP API。
- Next.config.ts 通过 rewrites 将 /api/engine/* 转发至 BACKEND_ORIGIN（默认 http://localhost:8787），生产环境统一单域名部署，worker 不对外暴露。
- 数据库使用 Drizzle ORM + PostgreSQL，schema 定义在 src/lib/db/schema/index.ts，迁移输出至 src/lib/db/migrations/pg。
- 队列消费通过 Next.js instrumentation.ts 在 Node 运行时启动 initQueue()，与 API 路由兜底初始化共享 globalThis 锚点，避免 split-brain。
- 依赖 @earendil-works/pi-ai 与 pi-agent-core 通过 serverExternalPackages 保持外部化，避免 Turbopack 动态 require 失败。
- pnpm workspace 管理 monorepo，server/ 作为独立子包通过 pnpm --filter 命令协同开发。
