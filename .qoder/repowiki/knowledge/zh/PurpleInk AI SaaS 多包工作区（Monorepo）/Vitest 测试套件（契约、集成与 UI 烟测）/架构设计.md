测试文件按功能域平铺在 tests/ 目录下，每个 .test.ts/.test.tsx 文件对应一个独立 describe 块，通过 vitest 的 describe/it/expect API 组织用例。测试主要分三类：
- 契约测试（contract）：如 app-route-contract.test.tsx、workspace-context-contract.test.ts、url-encoding-contract.test.ts，通过读取 src/ 源码并断言路径存在性、禁止模式匹配来维护架构约定。
- 集成测试：如 tts-orchestration.test.ts、golden-verification.test.ts、worker-* 系列，使用 node:fs/promises 创建临时目录（mkdtemp + tmpdir）隔离输入输出，并在 afterEach 中清理。
- UI 烟测：如 cvc-ui-smoke.test.tsx、providers-theme.test.tsx，使用 react-dom/server 的 renderToStaticMarkup 进行 SSR 静态渲染断言。
所有测试均从 ../server/src/ 或 ../src/ 导入被测模块，不依赖浏览器环境，属于纯 Node/Vitest 运行。
