- 每个测试文件使用单个 describe 块包裹，内部用 it 描述具体断言，统一从 'vitest' 导入 describe/expect/it。
- 涉及文件系统操作的测试通过 mkdtemp + tmpdir() 创建临时目录，并在 afterEach 中使用 rm(path, { recursive: true }) 清理。
- 契约类测试通过 readFileSync 读取 src/ 下源码并使用正则 or includes 断言禁止模式（如不包含 'LegacySidebar'、'LOCAL_WORKSPACE_ID'）。
- UI 组件测试统一使用 react-dom/server 的 renderToStaticMarkup 进行 SSR 静态渲染，再对生成的 HTML 字符串做 toContain 断言。
- 异步测试通过 vi.fn() 模拟外部依赖（如 synthesize、buildTrack、generatePlan），避免真实 I/O 或网络请求。
