- 所有 JSON 响应统一通过 `sendJson(res, status, body)` 写入，并附带 `Access-Control-Allow-Origin: *` 跨域头。
- Job 状态变更通过 `updateJob(id, patch)` 就地更新并自动刷新 `updatedAt`，阶段变化时追加一条带时间戳的日志到 `logs` 数组。
- 对外暴露的视图函数（`toPublicJob`、`toIntegratedJobView`）严格裁剪敏感字段，避免回传本机绝对路径、原始错误栈或输入正文。
- 内部 API 的请求体校验采用白名单 + 专用错误码（`INTERNAL_*`）模式，通过 `InternalRenderRequestError` 抛出并由上层映射为 422 响应。
- 异步任务通过 `AbortController` 管理生命周期，取消时检查 `controller.signal.aborted` 分支处理，并在 `finally` 中清理控制器引用。
