- 所有对外异步 API 在入口处立即调用 `options.signal?.throwIfAborted()` 以支持 AbortSignal 取消。
- 长耗时操作统一通过 `logger.info/warn/error` 记录结构化日志，关键阶段用 `pipeline:*` 命名空间区分。
- 外部命令执行统一走 `runCommand` / `runProcess` 包装，收集 stdout+stderr 字符串并在超时或 abort 时主动 kill 子进程。
- 可选配置通过解构 `options = {}` 提供默认值，未显式传参时使用合理默认（如 quality=standard、fps=30、soundEffects=off）。
- 结果对象采用扁平结构返回中间产物（如 `RenderResult`、`PipelineResult`、`WriteProjectResult`），便于调用方按需消费。
