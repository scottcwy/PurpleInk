本模块由三个文件构成清晰的三层分工：
- `project.ts`：纯 I/O 层，负责把 `VideoModel` 写成一个可被 hyperframes 识别的项目目录（`index.html`、`hyperframes.json`、`meta.json`、`package.json`、`assets/`），并提供 `writeProject`（模板路径）和 `writeProjectDirect`（LLM 多章节路径）两个写入入口。
- `render.ts`：外部工具封装层，通过 `node:child_process.spawn` 调用 `hyperframes check` 与 `hyperframes render`，自动探测 winget 安装的 ffmpeg 并前置到子进程 PATH，提供 `renderProject` 与 `verifyGolden` 两个导出函数。
- `run-pipeline.ts`：编排层，串联 `buildVideoModel → prepareNarrationAssets → writeProject/writeProjectDirect → renderProject → verifyGolden → muxNarration → applyWebsiteProceduralSfx` 完整流水线，暴露 `renderFromCapture`（已有 capture/）和 `urlToVideo`（URL→采集→视频）两个高层 API，并通过 `onPhase` 回调上报 queued/capturing/composing/rendering/verifying/muxing/done 阶段。
依赖方向单向向下：pipeline → project + render + chapters/* + tts/* + procedural-sfx；render 仅依赖 node 原生 fs/path/child_process 与 logger，不反向依赖 pipeline。
