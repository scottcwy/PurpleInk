- 每个章节通过固定的 `ChapterId` 字面量（ch1-opening/ch2-hero/ch3-showcase/ch4-proof/ch5-cta）标识，所有文件中的章节判断都基于这五个常量而非字符串硬编码。
- LLM 生成的 HTML 必须遵循 HyperFrames 规范：根元素带 `data-composition-id`、`data-width="1920"`、`data-height="1080"`，并通过 `window.__timelines[chapterId]` 注册 `gsap.timeline({ paused: true })`。
- 章节与镜头类型的映射在多处重复实现（`shotToChapter` 在 split.ts 与 template-fallback.ts 中完全一致），保持 ShotType → ChapterId 的双向一致性。
- 错误路径统一通过 `logger.warn`/`logger.error` 记录结构化日志，并使用 `summarizeComposeError` 或 `validationReason` 将异常摘要为稳定类别，避免泄露敏感信息。
- 模板渲染采用字符串拼接生成 `<template id="${chapterId}-template">` 包裹的子 HTML，CSS/JS 内联在 template 内部，确保每个章节自包含。
