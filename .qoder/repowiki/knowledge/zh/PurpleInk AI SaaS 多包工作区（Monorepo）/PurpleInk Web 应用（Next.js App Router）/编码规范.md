- 路由按功能域组织为 `(group)/` 目录并自带 layout.tsx，页面与 API 分离到各自子目录
- API 路由仅做参数校验与转发，业务逻辑下沉至 `features/<domain>/` 模块并通过 index.ts 暴露边界
- 共享基础设施集中在 `lib/` 下按能力域拆分（auth/db/stream/queue/storage/workflow 等），供上层统一 import
- UI 组件遵循 `*.demo.tsx` + `*.ts(x)` 成对编写，测试文件与源码同目录命名约定
- 服务端模块保持零副作用，动态依赖通过 `await import()` 延迟加载以满足 runtime-boundary 契约
