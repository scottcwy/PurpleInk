- 组件文件采用 `component.tsx` + 同名 `component.demo.tsx` 的配对结构，测试文件使用 `component.test.ts(.tsx)` 并列存放。
- 可交互组件通过 `control-motion.tsx` 中的 `ControlPressButton` / `ControlPressLink` 包装，统一使用 `data-motion-press` 标记与 `SPRING_SPATIAL_FAST` 弹簧过渡，保证按压反馈一致。
- 覆盖层组件通过 `mode: 'modal' | 'popover'` 联合类型区分渲染路径，并在根元素上设置 `data-slot="overlay-root"` 与 `data-overlay-mode="<mode>"` 作为样式与测试选择器。
- 样式类名通过 `cn()` 组合，变体与尺寸以 `Record<Variant, string>` 常量集中定义（如 `VARIANTS`、`SIZES`），并通过 `buttonClassName` 等工厂函数暴露 SSOT。
- 全局状态（如 Toast）采用模块级单例 + 订阅者模式（`subscribe` 返回取消函数），并提供 `getSnapshot` / `getServerSnapshot` 以兼容服务端渲染。
- 跨层类型通过 `export type { ... } from '@/features/...'` 重导出（如 `ui/node/types.ts`），避免组件直接 import 业务层代码。
