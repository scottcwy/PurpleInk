模块按职责划分为三个子目录：
- `ui/`：应用级基础组件与复合控件。以 `button.tsx`、`dialog.tsx`、`popover.tsx` 等文件为单一职责原语，通过 `control-motion.tsx` 统一注入 motion 按压动效；覆盖层体系由 `overlay-root.tsx` 作为入口，将 `mode: 'modal' | 'popover'` 分派到两个 Surface 组件，并依赖 `overlay-phase.ts`（有限状态机）、`overlay-motion.ts`（motion variants）、`overlay-platform.ts`（平台适配 hook）、`overlay-scroll-lock.ts`、`overlay-focus.ts` 等纯逻辑模块完成动画阶段、滚动锁定与焦点管理。
- `marketing/`：面向营销页面的业务区块（hero、pricing、faq、footer、header 等），通过 `providers.tsx` 暴露 `MarketingProviders` 聚合全局 Provider（如 SmoothScroll），供页面根节点包裹。
- `icons/`：品牌 SVG 图标，每个图标一个组件文件，附带 `.demo.tsx` 用于 Storybook 或开发预览。

组件间依赖方向单向向下：业务组件 → ui 原子组件 → 纯逻辑 hook（overlay-*、toast-store）。`ui/node/` 子目录通过 `types.ts` 重新导出 `@/features/canvas/types` 中的类型，使节点类组件复用画布领域类型而不直接耦合 features 层。所有可交互组件遵循 `*.demo.tsx` + `*.test.ts` 的配套文件约定，便于独立开发与测试。
