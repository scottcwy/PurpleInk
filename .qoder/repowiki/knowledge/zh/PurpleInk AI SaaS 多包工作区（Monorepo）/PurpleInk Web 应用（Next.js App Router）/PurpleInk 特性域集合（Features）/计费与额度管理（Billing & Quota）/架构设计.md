模块按职责划分为清晰层次：
- 领域层 `domain.ts` 定义 PlanKey、PLAN_DEFINITIONS、滚动周期与兑换码转换策略，不依赖数据库。
- 契约层 `contracts.ts` 暴露 BillingProjection 类型及 QuotaExhaustedError、BillingIdempotencyConflictError 两个业务异常，作为跨层边界。
- 服务层 `period-service.ts` 负责工作区订阅权益与使用周期的创建/确保、配额校验（assertBillingAvailable/assertBillingCapacity）和计费投影聚合。
- 账本层 `ledger.ts` 基于 Drizzle ORM 对 aiInvocations、usagePeriods 等表执行预留（reserveManagedInvocation）、结算（settleManagedInvocation）、失败回滚（failManagedInvocation/releaseManagedReservation）及孤儿调用补偿（reconcileOrphanedManagedInvocations），全部通过事务 + for('update') 行锁保证一致性。
- 费率计算 `rate-card.ts` 提供 BillableUsage/MaximumUsageEstimate 到 CNY Micros 的换算，支持 text/vision/tts/asr/workflow 多种计量单位。
- 兑换码 `redemption.ts` 使用 HMAC-SHA256（带 pepper）哈希代码，通过 advisory lock + redemptionAudits 实现幂等兑换与审计。
- UI 子目录 `ui/` 仅消费脱敏后的 BillingUiProjection（由 `projection-contract.ts` 校验），包含页面视图、用量面板与兑换表单。
- 所有对外能力通过 `index.ts` 统一 re-export，外部仅依赖该入口。
