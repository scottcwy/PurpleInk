本模块是 PurpleInk 的领域特性聚合层，14 个子模块各自独立封装一个业务域（ai、artifacts、audio、auth、billing、canvas、credentials、director、navigation、projects、render、routing、usage、website），并通过各自的 index.ts 仅导出对外契约（类型、服务函数、仓储接口），内部实现细节不泄露。

- 跨域依赖方向：projects/canvas/director/render/website 等生产流水线模块依赖 ai（AI 网关）、artifacts（产物读写）、billing（计费结算）、credentials（凭据加密）、routing（路由配置）、usage（用量统计）；auth 被所有需要鉴权的模块间接使用；navigation 仅服务于前端壳层。
- 数据访问统一通过 PostgreSQL 仓储抽象（如 PostgresProviderCredentialStore、PostgresProjectSourceRepository、PostgresMediaRouteRepository 等），测试侧通过 .pg.test.ts 后缀配合 fixture 运行。
- 各模块遵循「index.ts 作为唯一公开入口」约定，外部只能通过 re-export 的契约调用，避免直接 import 内部文件。
- 无全局编排器：模块间通过函数参数注入依赖（如 Dependencies 类型）而非单例容器，由上层组装时传入。
