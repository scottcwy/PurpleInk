模块以 `index.ts` 作为统一对外导出入口，内部按职责拆分为多个独立文件：
- `service.ts`：服务端数据访问层（`server-only`），通过 Drizzle ORM 查询 `artifacts` 表并提供 `getLatestArtifact`、`getArtifactDescriptor`、`readArtifact` 三个读取 API，其中 `readArtifact` 再调用 `@/lib/storage` 获取二进制内容。
- `commit.ts`：产物写入层，封装 `commitArtifactRecord`、`commitArtifactRecords`（批量事务）、`commitDerivedArtifact`（派生产物专用）三个提交函数，均通过 `withTransaction` 保证原子性，并通过 `lockAggregate` 对 aggregate（project/node）加行锁防止并发覆盖。
- `attempt-ownership.ts`：归属与栅栏逻辑，定义 `CommitArtifactInput`、`ArtifactAggregateType` 等类型，提供 `resolveCurrentAttemptId`、`resolveDerivedSourceAttemptId`、`assertAttemptFence`、`assertAttemptExists` 等函数，确保产物归属于正确的 running attempt 或来源 attempt。
- `content-type.ts` 与 `preview-mode.ts`：纯函数映射，零依赖，分别将 `kind` 映射为 HTTP content-type 和客户端预览模式，避免被 `server-only` 的 service 层污染。
- `download.ts`：基于 content-type 推导下载文件名与 Content-Disposition，文件名由 kind + content hash 前缀构成，保证 ASCII 安全。
依赖方向单向：`commit.ts` → `attempt-ownership.ts`；`download.ts` → `content-type.ts`；`index.ts` 仅做 re-export，无业务逻辑。
