- 对外 API 统一通过 `index.ts` 集中 re-export，内部实现文件不直接暴露给外部消费者。
- 所有涉及数据库写操作的函数都通过 `withTransaction` 包裹，并在关键步骤插入 `signal?.throwIfAborted()` 支持取消。
- 产物归属校验采用两阶段：先通过 `resolve*AttemptId` 解析目标 attempt，再通过 `assertAttemptFence`/`assertAttemptExists` 在事务内二次验证，防止竞态。
- 纯函数映射（content-type、preview-mode）保持零依赖，不与 `server-only` 的数据层耦合，以便在客户端或服务端复用。
- 错误信息使用中文描述且包含上下文参数（如 projectId/aggregateId/kind），便于定位问题。
