- 导航激活项与侧栏模式均通过纯函数（`resolveActiveSection`、`resolveSidebarMode`）从输入参数推导，组件内不直接持有分支逻辑。
- URL 构造统一收口到 `products-routes.ts` 中的 `*Href` 函数，并使用 `encodeURIComponent` 对路径段进行转义，禁止在组件中拼接字符串。
- Client Component 通过 `'use client'` 指令显式标注，Server Component 则保持无指令形式，按职责严格区分。
- 上下文采用 publish/consume 模式：`NavContextStore` 暴露 `context` 与 `publish` 方法，消费者通过 `useContext` 订阅而非直接修改。
- 样式类名统一通过 `cn()` 合并，尺寸常量（如 `SIDEBAR_DEFAULT_WIDTH`、`BP_SIDEBAR_HIDDEN`）从 `@/lib/layout/breakpoints` 集中引入。
