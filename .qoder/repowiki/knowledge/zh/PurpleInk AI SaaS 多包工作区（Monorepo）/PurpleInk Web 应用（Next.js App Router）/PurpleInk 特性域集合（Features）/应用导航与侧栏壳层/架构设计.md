模块以 React Server Components 与 Client Components 分层组织：
- `app-shell.tsx` 作为服务端入口，挂载 `NavContextProvider` 并组合 `AppSidebarShell` 与内容区，是 `(app)` layout 的唯一集成点。
- `nav-context.tsx` 通过 `createContext` + `useEffect` publish 模式实现页面→侧栏的双向数据流：页面调用 `usePublishNavContext` / `<PublishNavContext>` 发布 `{projectId, rendererNodeId}`，侧栏通过 `useNavContext` 读取，保证切页时侧栏不重挂载。
- `sidebar-mode.ts` 暴露纯函数 `resolveSidebarMode`（hidden/rail/expanded 互斥）和 `resolveActiveSection`（委托给 `products-routes.ts`），将响应式逻辑与业务路由解耦。
- `products-routes.ts` 集中定义 `PRODUCTS_ROUTES` 常量与 URL 构造器（`productCanvasHref` 等），并以 `startsWith` 前缀匹配实现 `resolveProductsSection`。
- `app-sidebar.tsx` 仅负责菜单项渲染与账号/登出 UI；`app-sidebar-shell.tsx` 处理媒体查询、持久化折叠状态、抽屉遮罩与 AnimatedAside 宽度动画。
- `collapsible-panel.tsx` 封装 `AnimatedAside`（motion/react 宽度过渡）与 `DrawerOverlay`（基于 `OverlayRoot` 的 top-layer/焦点管理），为侧栏在不同视口下提供一致的交互容器。
- `types.ts` 仅声明 `AppSection` 联合类型，被各组件通过 import 复用，避免硬编码字符串。
