模块以 `index.ts` 作为公开边界，仅导出三类能力：会话解析与守卫（`api-session`、`page-session`）、业务用例（`account-service`、`verification-service`、`human-check-service`）以及输入契约（`schemas`、`errors`）。仓储层（`auth-repository`、`verification-repository`）和派生密钥（`signing-key`）刻意不导出，外部只能通过本模块暴露的接口访问。

内部分层清晰：
- 用例层：`account-service.ts`（authenticate/register/resetPassword）、`verification-service.ts`（requestVerificationCode/consumeVerificationCodeFor）、`human-check-service.ts`（issueChallenge/passesHumanCheck），组合底层能力并处理安全语义（防枚举、防时序攻击）。
- 领域工具：`session.ts`（会话令牌签发/解析/吊销）、`throttle.ts`（固定窗口限流）、`password.ts`、`verification-code.ts`、`mail-failure.ts`、`next-path.ts`、`honeypot.ts`。
- 基础设施：`mailer.ts`、`http.ts`、`unauthenticated-error.ts`。
- 测试文件按 `*.test.ts` / `*.pg.test.ts` 命名区分单元测试与 PostgreSQL 集成测试。

依赖方向单向向下：用例 → 领域工具 → 仓储/邮件/数据库；跨域调用统一走 `index.ts` 导出的白名单。
