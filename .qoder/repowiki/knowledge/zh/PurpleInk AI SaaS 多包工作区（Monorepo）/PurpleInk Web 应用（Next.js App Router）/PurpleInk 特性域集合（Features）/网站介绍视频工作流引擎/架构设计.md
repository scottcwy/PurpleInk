模块以 `index.ts` 作为统一导出入口，按职责拆分为多个独立文件：
- `engine-client.ts`：通过 HTTP 调用外部渲染引擎（`/internal/render`、`/internal/jobs/*`），使用 Zod 严格校验响应，封装为 `WebsiteEngineClient` 并提供 `readResponseBodyWithLimit` 限制视频大小。
- `website-engine-execution.ts`：编排引擎启动、轮询进度、超时控制与取消，将引擎阶段映射为工作流阶段。
- `website-execution.ts`：顶层执行入口 `runWebsiteVideo`，组合项目加载、计费包装、引擎执行、输出持久化与阶段投影，依赖注入 `WebsiteExecutionDependencies`。
- `managed-billing.ts` + `managed-billing-identity.ts` + `managed-billing-lifecycle.ts`：基于共享计费模块的托管式计费流程，包含容量预估、预留、开始标记、实际结算与释放。
- `website-output.ts`：MP4 字节校验（ftyp/moov/mdat box 解析）、存储写入、Artifact 提交与失败回滚。
- `website-stage-contract.ts`：定义工作流阶段常量、状态投影接口与阶段转换规则，是各子模块共享的类型契约。
- `website-stage-repository.ts`：PostgreSQL 实现的阶段投影器。
- `website-queue-handler.ts`：队列适配器注册、去重入队（PG advisory lock + fingerprint）、终端错误语义（禁止隐式重试）。

依赖方向单向向外：执行层依赖计费、存储、数据库、队列与外部引擎；所有外部依赖均通过依赖注入接口传入，便于测试替换。
