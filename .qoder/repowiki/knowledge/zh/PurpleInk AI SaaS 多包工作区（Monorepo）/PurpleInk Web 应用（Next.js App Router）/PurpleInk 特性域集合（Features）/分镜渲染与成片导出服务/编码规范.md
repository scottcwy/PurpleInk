- 所有服务端文件顶部显式引入 `'server-only'`，标记仅可在服务端执行。
- 外部依赖通过函数参数或构造函数注入（如 `storage`、`db`、`queue`、`transitionNodeStatus`），并提供 `createXxxDependencies()` 工厂返回默认绑定，便于测试替换。
- 数据库访问统一通过 `withTransaction` 包裹写操作，并使用 `currentWorkspaceId()` 限定工作区范围。
- 错误处理采用自定义 Error 子类（如 `ExportExecutionError`）并携带结构化 `safeDetails`，同时用 `exportPhase`/`advanceWithoutMasking` 等包装器统一捕获与降级。
- 对外 API 通过 `index.ts` 集中 re-export 类型与函数，内部实现保持模块私有，避免直接 import 子文件。
- 字符串键（如 `renderOutputKey`、`thumbnailOutputPath`、`finalVideoStorageKey`）集中定义在对应模块中，作为跨模块共享的路径约定而非散落在调用处。
