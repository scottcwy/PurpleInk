本模块采用仓储模式，通过两个对称的类 `PostgresMediaRouteRepository` 与 `PostgresModelRouteRepository` 分别管理 `mediaRoutes` 与 `modelRoutes` 两张表。每个仓储类依赖注入 `DatabaseProvider`（延迟获取 Drizzle ORM 数据库连接）和 `ProviderCredentialStore`（用于在 `resolve` 阶段加载 provider 密钥），对外暴露 `save/find/resolve/remove` 四个方法。`index.ts` 作为统一导出入口，仅重新导出类与类型，不引入额外逻辑。数据访问层使用 Drizzle ORM 的 `insert...onConflictDoUpdate` 实现幂等写入，并通过 `workspaceId + taskKind` 联合主键保证唯一性；`Resolved*Route` 类型在基础 Route 上扩展 `secret` 字段，将凭据解耦到独立的 credentials 模块。
