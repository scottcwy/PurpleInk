模块以 feature 边界组织，职责清晰分层：
- `contracts.ts` 定义对外契约类型（`AiUsageProjectionV1`、`AiUsageView`、`AiUsageRange`、`AiUsageBreakdownRow`），是服务端与客户端共享的唯一类型来源。
- `service.ts` 为服务端入口（`'server-only'`），通过 Drizzle ORM 查询 `aiInvocations`、`telemetryCutovers`、`usagePeriods` 表，按 `view` 分支选择 `accountRows`（按用户）或 `managedCycleRows`（按工作区当前周期），再委托 `aggregation` 完成汇总。
- `aggregation.ts` 纯函数层，实现 `summarize`、`buildSeries`、`breakdown` 等聚合逻辑，不依赖数据库。
- `time-range.ts` 处理时区相关的日期键生成（`recentDateKeys`、`dateKeysBetween`、`zonedStart`），使用 `Intl.DateTimeFormat` 解析偏移量。
- `use-ai-usage-projection.ts` 为 `'use client'` React Hook，通过 `fetch('/api/ai-usage')` 拉取数据并维护 loading/error/ready 状态。
- `index.ts` 仅重导出类型和 `getAiUsageProjection`；`client.ts` 仅重导出类型和 Hook，形成 server/client 双入口。
依赖方向单向：service → aggregation + time-range + contracts；hook → contracts；无反向依赖。
