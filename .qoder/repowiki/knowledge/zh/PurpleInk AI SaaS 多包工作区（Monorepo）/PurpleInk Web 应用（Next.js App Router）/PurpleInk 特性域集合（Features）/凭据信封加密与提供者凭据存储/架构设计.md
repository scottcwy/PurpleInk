模块按职责拆分为两个核心文件：`credential-envelope.ts` 实现纯函数式的凭据信封算法（AES-256-GCM + 随机 nonce + AAD 绑定 workspaceId/provider），对外暴露 `createCredentialEnvelope`、`openCredentialEnvelope`、`encodeCredentialEnvelopeWire`、`decodeCredentialEnvelopeWire`、`parseCredentialMasterKey` 及 `CredentialEnvelope` 类型；`provider-credential-store.ts` 定义 `ProviderCredentialStore` 接口并提供 `PostgresProviderCredentialStore` 实现，使用 Drizzle ORM 对 `providerCredentials` 表进行 upsert、查询与描述，所有敏感字段在落库前经信封加密、读取时解密。`index.ts` 作为统一导出入口，将两类 API 聚合暴露给上层 feature。依赖方向单向：store → envelope，envelope 仅依赖 Node `node:crypto`，无外部副作用。
