- 每个 Provider 的配置模块都暴露 `describe*Config` / `get*Config` / `save*Settings` 三件套，并通过可选的 `dependencies` 参数注入存储实现以便测试替换。
- 数据库操作统一通过 Drizzle ORM 在 `transaction` 回调内执行，并使用 `sql` 模板字面量拼接 `pg_advisory_xact_lock(hashtextextended(...))` 进行跨进程互斥。
- 对外 API 的错误统一抛出 `RouteContractError` 或自定义 `ProviderRequestError`（带 `kind` 字段区分 rate_limit/unavailable/network 等），由上层捕获并映射到调度策略。
- 所有服务端专用文件顶部显式添加 `'server-only'` 注释，禁止客户端导入，确保凭据与 DB 访问不会泄露到浏览器。
- Provider ID 全部从 `AI_PROVIDER_IDS` 常量派生类型，新增 provider 必须同时更新 registry、schema 枚举与路由能力声明，保持单一数据源。
