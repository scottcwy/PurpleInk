- 所有对外接口通过 TypeScript interface 定义（如 AdvanceRepository、StageRunnerDependencies、DirectorRuntimeRepository），实现类在模块内部构造并注入，避免直接 import 耦合。
- 数据库访问统一通过 `withTransaction` 包裹，并使用 `currentWorkspaceId()` 强制 workspace 隔离，错误信息包含中文描述便于调试。
- 产物写入走 `writeValidatedArtifact` + Zod schema 预校验，校验失败抛出 `ArtifactValidationError`，并由 stage-runner 统一捕获记录到 `directorError`。
- AI 模型选型集中在 `pi-provider.ts` 的 `createDirectorModelRuntime`，按 `DIRECTOR_NODE_TYPES` 与 `resolveDirectorModelTarget` 决定 provider/model/baseUrl/apiKey，禁止在调用侧拼凑凭据。
- 阶段提示词按阶段拆分为独立文件（`prompts/*.ts`），每个文件用 zod schema 约束输入结构并以 `buildXxxPrompt` 函数返回字符串模板。
- 异步操作普遍支持 `AbortSignal` 参数并在关键分支后调用 `signal?.throwIfAborted()`，确保取消传播贯穿 session、storage 与 DB 调用链。
