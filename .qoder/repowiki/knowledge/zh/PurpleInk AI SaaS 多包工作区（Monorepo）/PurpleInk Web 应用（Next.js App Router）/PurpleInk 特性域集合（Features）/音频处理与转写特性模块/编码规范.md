- 所有对外暴露的输入参数均使用 zod schema 定义并通过 `.parse()` 校验，类型通过 `z.infer<typeof schema>` 推导。
- 依赖注入采用函数参数传入 dependencies 对象，并提供 `defaultDependencies()` 工厂函数返回默认实现，便于单元测试时替换。
- 异步工作流的状态通过联合类型表达（如 `AudioTranscriptionState` 的 running/waiting/ready/failed 四种状态），并在异常分支中统一调用 `recordState` 和 `transition` 收敛状态。
- 音频字节的内容寻址通过 SHA-256 计算 contentHash，并在读取时校验 sizeBytes 与 contentHash 双重一致性，防止存储损坏或篡改。
- 多供应商路由通过常量枚举（如 `MEDIA_PROVIDERS`、`CUSTOM_TTS_PROVIDER`）集中管理，新增供应商需同时更新枚举与路由判断逻辑。
- 错误处理区分可重试的 `ProviderQueueDeferral` 与业务失败，对前者透传让上层队列调度恢复，后者通过 `classifyWorkflowError` 投影为统一的 `WorkflowErrorProjection`。
