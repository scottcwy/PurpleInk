- 对外部 feature 模块的依赖一律通过运行时 `import()` 动态加载，避免 lib/queue 与 features 之间产生静态循环依赖。
- 跨进程共享的状态（队列实例、初始化标志）统一挂载到 `globalThis` 上并以 `__cvcQueue*` 前缀命名，确保 HMR 和多模块图下的单例语义。
- 错误分类统一委托 `classifyWorkflowError` 生成 `WorkflowFault`，队列层禁止自行用字符串匹配判断可重试性。
- 需要 auth 上下文的后台操作（如节点状态投影、重试复位）通过 `runInAuthContext({ workspaceId, userId: SYSTEM_USER_ID })` 显式建立上下文，而非依赖请求上下文。
- 所有涉及时间的决策（租约到期、退避 visibleAt、重试窗口）优先使用 DB 时钟 `sql\`now()\`` 计算，避免应用与数据库时钟漂移。
- 配置文件读取遵循 DB > env > 代码默认 的单一真值优先级链，且返回值标注 source 字段以便 UI 展示来源。
