模块采用「规则 + 扫描器」的简单分层：rules.ts 定义 DeterminismRule 接口与 DETERMINISM_RULES 常量数组（每个规则含 id、RegExp pattern、message）；check.ts 提供核心扫描逻辑 checkSource，逐行对 source.split(/\r?\n/) 应用所有规则的 pattern.test()，收集 Violation/DeterminismViolation 对象；index.ts 作为统一导出入口，对外暴露 checkDeterminism（兼容旧调用方）、checkSource（新 Tool 边界首选）、isDeterministic 以及类型。依赖方向单向：check.ts → rules.ts，测试文件 check.test.ts 使用 vitest 验证三类场景（flag 非确定性、pass seek 驱动代码、直接检查 HTML 源）。
