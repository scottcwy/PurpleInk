本模块由三个相互独立的纯函数/类型文件组成，无内部依赖关系：
- `api.ts`：定义后端 Job 生命周期类型（JobPhase、JobView、RenderRequest）并通过 fetch 封装 startRender/getJob/pollUntilDone/downloadVideo 等 HTTP 调用，默认基址通过环境变量 NEXT_PUBLIC_API_BASE 或 /api/engine 覆盖，由 next.config.ts 的 rewrites 反向代理到渲染 worker。
- `utils.ts`：基于 clsx + tailwind-merge 的 cn() 工具，用于安全合并条件 className 并解决 Tailwind 冲突。
- `theme-mode.ts`：定义 ThemeMode 联合类型及 THEME_MODE_ORDER 常量，提供 nextThemeMode/themeModeLabel/applyTheme/resolveDarkMode/isThemeMode 等纯函数，通过操作 document.documentElement.classList 切换 'dark' 类实现主题。
三个文件均只暴露命名导出，不持有状态，可被任意页面或组件直接 import。
