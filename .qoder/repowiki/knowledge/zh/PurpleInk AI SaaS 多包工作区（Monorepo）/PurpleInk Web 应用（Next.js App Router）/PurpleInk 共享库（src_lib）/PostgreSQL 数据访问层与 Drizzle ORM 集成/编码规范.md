- Schema 表定义统一使用 drizzle-orm/pg-core 的 `pgTable` 声明，并通过 CHECK 约束与 `$type<T>()` 保持类型与数据库一致性
- 跨仓库原子操作通过 `withTransaction(database, (tx) => ...)` 显式划定事务边界，而非隐式传播
- 数据库连接采用进程内全局单例模式，通过 `globalThis` 存储 pending Promise 实现惰性初始化与失败重试
- 测试数据库通过 advisory lock 确保多进程隔离，并在每次 reset 时 DROP/CREATE public 和 drizzle schema 后重放迁移
- 迁移文件遵循 `NNNN_description.sql` 编号命名规范，并由 `_journal.json` 严格校验索引与时间戳单调递增
