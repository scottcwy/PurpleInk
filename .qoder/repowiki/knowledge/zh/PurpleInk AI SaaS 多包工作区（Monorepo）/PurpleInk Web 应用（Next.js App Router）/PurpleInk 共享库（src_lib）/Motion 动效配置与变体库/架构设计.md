模块按职责分为三层：
- `tokens.ts` 定义所有动效原语（DURATION、EASE）和 Transition 常量（TRANSITION_*、SPRING_SPATIAL_*），是唯一的权威来源，与 CSS 变量 `--duration-*` / `--ease-*` 一一对应。
- `variants.ts` 组合 tokens 生成高阶 Variants（fadeInUp、scrimFade、slideInLeft/Right、collapse），供组件直接消费。
- `config.tsx` 暴露 AppMotionConfig 客户端组件，作为应用根节点包裹，注入 reducedMotion="user" 和默认 transition。
依赖方向单向：variants → tokens ← config，无循环引用；测试文件 `tokens.test.ts`、`variants.test.ts` 分别校验 token 与 CSS 同步及变体行为。
