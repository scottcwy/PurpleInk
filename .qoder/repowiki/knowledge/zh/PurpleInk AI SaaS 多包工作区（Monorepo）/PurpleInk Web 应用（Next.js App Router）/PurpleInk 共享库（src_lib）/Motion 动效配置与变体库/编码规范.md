- 所有动效常量使用 as const 断言，确保 TypeScript 推断出精确字面量类型。
- Transition 常量以 TRANSITION_ 前缀命名，Spring 参数以 SPRING_SPATIAL_ 前缀区分 spatial 与 effects 两类属性。
- 退出动画统一使用 TRANSITION_EXIT（禁止 spring），进入动画使用 TRANSITION_ENTER 或对应 Spring 档位。
- Variants 遵循 hidden/visible 状态机约定，必要时补充 exit 状态处理离场动画。
- 注释中引用 docs/conventions/motion-interaction.md 的章节编号，将实现与动效规范文档绑定。
