模块由两个正交的子能力组成：
- `session-cookie.ts`：封装 Next.js `cookies()` API，定义会话 cookie 名称 `cvc_session`、30 天 TTL 与安全属性（`httpOnly`、`sameSite: 'lax'`、生产环境 `secure`），提供 `attachSessionCookie`、`clearSessionCookie`、`readSessionToken` 三个导出，用于登录成功后写入、登出时清除、以及从请求中读取高熵随机 token。
- `workspace-context.ts`：基于 Node `AsyncLocalStorage` 实现跨 await 边界的请求级上下文，暴露 `runInAuthContext`、`currentWorkspaceId`、`currentUserId`、`currentAuthContext` 及 `SYSTEM_USER_ID` 常量；通过 `server-only` 强制仅服务端使用，且对缺失上下文直接抛错而非静默回退，避免跨账户串号。
依赖方向单向：上层业务调用这两个模块，二者不互相依赖，也不直接访问数据库或用户表。
