src/lib 是 PurpleInk 的横向基础设施层，按职责拆分为多个子目录，每个子目录对外暴露单一能力的 TypeScript 模块，被上层页面、组件和后端 worker 共同引用。
- 顶层文件 api.ts、metadata.ts、site-config.ts、utils.ts、theme-mode.ts 提供跨领域通用的 API 客户端、Next Metadata 工厂、站点常量、clsx+tailwind-merge 的 cn 工具与主题模式切换逻辑。
- 业务域子模块（auth、config、db、determinism、gsap、hooks、layout、motion、queue、storage、stream、tts、workflow）各自封装一个完整能力，通过纯 TS 接口向上暴露，不互相直接耦合，而是由上层编排组合。
- 进程内通信通过 stream 模块的 StreamBus/StatusBus 单例（globalThis 挂载）实现 SSE 流式输出与节点状态广播；队列任务由 queue 模块基于 PostgreSQL 驱动，被 workflow 注册表调度。
- 存储抽象由 storage.StorageAdapter 统一，默认本地文件系统实现，便于替换为云存储。
- 确定性保障由 determinism 模块在构建期静态扫描 shot 代码，确保渲染可重现。
- 所有子模块遵循统一的导出风格：index.ts 聚合 re-export，类型定义与实现分离，测试文件与源码同目录。
