模块采用适配器模式：`types.ts` 声明 `StorageAdapter` 接口，约定 key 相对路径的读写、存在性检查、本地绝对路径解析、删除以及临时工作目录的创建与清理；`local-fs.ts` 通过 `LocalFsStorage` 类实现该接口，所有 key 经私有 `resolve()` 方法在 `root` 目录下解析并做路径穿越防护；`index.ts` 作为进程内单例入口，使用 `server-only` 确保仅在服务端加载，并通过 `ARTIFACTS_DIR` 配置根目录初始化单例 `storage`，同时重新导出 `LocalFsStorage` 类和 `StorageAdapter` 类型供外部使用。依赖方向单向：`local-fs.ts` → `types.ts`，`index.ts` → `local-fs.ts` + `@/lib/config/paths`。
