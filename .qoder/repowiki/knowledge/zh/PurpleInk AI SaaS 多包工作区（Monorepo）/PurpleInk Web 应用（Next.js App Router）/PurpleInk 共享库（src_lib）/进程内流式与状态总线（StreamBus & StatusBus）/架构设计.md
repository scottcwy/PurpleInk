模块由两个并列的纯内存 EventBus 组成：
- `stream-bus.ts`：以 `${projectId}:${nodeId}` 为键维护有界字符串缓冲（上限 256KB，超出截断并置 truncated），通过 `publish/markDone/markError` 推送 delta/done/error 事件，新订阅者先原子回放 snapshot。
- `status-bus.ts`：以 `projectId` 为键维护每节点最新状态的 Map，通过 `publishStatus/publishTopology` 推送 node-status/topology 事件，订阅时先回放 snapshot。
两者共享相同模式：`ensure` 懒创建 Entry、`emit` 遍历 Set 广播且捕获单个 listener 异常、`subscribe` 返回退订函数并在末位订阅者断开后通过 `CLEANUP_DELAY_MS=30s` 延时清理缓冲、`maybeCleanup` 使用 `setTimeout(...).unref()` 避免阻止进程退出。
每个 Bus 都通过 `globalThis.__cvcXxxBus ??= new XxxBus()` 导出进程级单例，规避 Next.js/Turbopack 按路由入口编译导致的模块重复求值问题。模块顶部 `import 'server-only'` 强制仅在服务端使用，不依赖 features/canvas，仅通过同形字面量联合类型保持与上层 NodeStatus 兼容。
