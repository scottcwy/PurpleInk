- 每个 Bus 类通过 `globalThis.__cvcXxxBus ??= new XxxBus()` 暴露进程级单例，避免 HMR 导致的多实例 split-brain。
- 事件模型采用 discriminated union（`type` 字段区分 snapshot/delta/done/error 等），订阅者先收到 snapshot 再收增量事件。
- `emit` 中对每个 listener 调用包裹 try/catch，确保单个订阅者异常不影响其他订阅者与主流程。
- 订阅/退订分离：`subscribe` 只读不创建 entry，退订函数负责从 listeners Set 移除并在末位订阅者断开时触发延时清理。
- 缓冲清理统一使用 `CLEANUP_DELAY_MS` 常量 + `setTimeout(...).unref()` 模式，允许进程在无活跃订阅时正常退出。
- lib 层通过独立声明的类型（如 `NodeStatusValue`、`StreamError`）与上层 features 保持结构兼容，但不反向依赖 features。
