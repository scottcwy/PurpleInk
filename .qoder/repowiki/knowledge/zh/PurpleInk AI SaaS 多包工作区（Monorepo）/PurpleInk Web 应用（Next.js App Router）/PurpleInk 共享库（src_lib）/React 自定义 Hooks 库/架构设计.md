本模块为纯客户端 Hook 集合，每个文件导出一个独立 Hook（或配套工具函数），通过 `'use client'` 指令确保仅运行在浏览器端。按能力分为三类：
- 浏览器能力封装：`use-fullscreen`（Fullscreen API + `useSyncExternalStore`）、`use-media-query`（`matchMedia` + `useState/useEffect`）、`use-local-time-zone`（IANA 时区读取）。
- 持久化与 UI 状态：`use-persistent-toggle`（localStorage 布尔开关）、`use-resizable-panel`（pointer events 拖拽调宽 + localStorage 持久化，含纯函数 `clampWidth` 便于单测）。
- SSE 流式订阅：`use-project-status-stream` 与 `use-stage-stream` 均基于原生 `EventSource`，采用「连接键 + 派生复位」模式避免 effect 内同步 setState，并通过纯归约函数（如 `applyStreamEvent`）处理事件，使状态更新可测试。
- 基础设施 Hook：`use-hydrated` 作为其他 Hook（如 `use-theme-mode`）的依赖，统一解决 SSR hydration 首帧差异问题。
依赖方向单向向下：业务 Hook 不互相强耦合，仅 `use-theme-mode` 组合 `use-hydrated`。
