- 所有 Hook 文件顶部以 `'use client'` 指令标记，确保仅在浏览器端执行。
- SSR/hydration 敏感的状态通过 `useSyncExternalStore` 配合 serverSnapshot/clientSnapshot 实现，首帧返回安全默认值（如 `false`、`UTC`）。
- SSE 流式 Hook 使用「连接键 + 派生复位」模式：内部态附带 `key` 字段，切换参数时直接返回初始态，新连接建立后再写入带新 key 的态，避免 effect 内同步 setState。
- 状态更新全部下沉到事件回调中，通过 `setState(prev => ...)` 的函数式更新保证竞态安全，effect 体内只做订阅与清理。
- localStorage 读写包裹 try/catch 并忽略失败，兼容私有模式与 SSR 环境。
- 可复用的纯计算逻辑（如 `clampWidth`、`applyStreamEvent`、`resolveHydratedThemeMode`）独立导出以便单元测试。
