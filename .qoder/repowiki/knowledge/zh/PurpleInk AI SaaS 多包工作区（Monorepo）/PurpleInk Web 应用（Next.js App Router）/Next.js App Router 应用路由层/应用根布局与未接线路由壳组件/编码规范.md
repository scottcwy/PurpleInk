- C 层组合组件只拼装已登记的 UI 原子（如 `EmptyState`、`Button`、`Dialog`），禁止引入平行的卡片或空状态视觉。
- 未接线路由统一通过 `UnwiredPanel` 声明 `sources`（真实领域实体名）和可选 `futureGuard`，禁止渲染假百分比、假状态或可点击但无行为的按钮。
- 客户端组件使用 `'use client'` 指令并在顶部集中声明所有本地 state、ref 与副作用，提交逻辑通过 `submittingRef` 防抖避免重复提交。
- 错误处理统一走 `handleAuthError` 或设置 `error` state 后通过 `Toast` 展示，不在组件内直接 alert/prompt。
- 组件 props 以 TypeScript interface 显式导出，字符串选项使用 `as const` 字面量数组保证类型收窄。
