模块按职责分为三层：
- 根入口层：`layout.tsx` 作为 Next.js App Router 的 `RootLayout`，注入字体变量、viewport、SEO metadata（来自 `@/lib/metadata`），并通过内联脚本在 SSR 阶段同步 `theme-mode` 到 `document.documentElement.classList`。
- Provider 层：`providers.tsx` 暴露 `RootProviders`，用 `next-themes` 的 `ThemeProvider` 包裹全局主题（class 模式、system 默认、`storageKey="theme-mode"`），并挂载 `ToastViewport`。
- 路由壳组件层：`_components/` 下提供 C 层组合组件——`route-shell-page.tsx` 复用 `TopBar` + `UnwiredPanel` 构成「未接线路由」整页壳；`unwired-panel.tsx` 是唯一的「这页还没做」占位面板，强制声明未来数据来源与前置条件；`route-status.tsx` 统一 404/错误边界的空状态展示；`new-project-dialog.tsx` 封装新建项目的完整表单流程，通过 `buildNewProjectInput` / `validateNewProjectInput` 与 `project-create-client` 协作。
依赖方向单向向外：本模块仅消费 `@/components/ui/*`、`@/features/*`、`@/lib/*`，不反向依赖业务路由。
