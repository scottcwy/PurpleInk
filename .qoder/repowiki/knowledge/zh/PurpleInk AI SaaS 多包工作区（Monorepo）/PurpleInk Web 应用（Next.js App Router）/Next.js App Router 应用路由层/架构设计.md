本模块以 `src/app/` 为根，采用 Next.js App Router 的路由组（`(marketing)`、`(public)`、`(auth)`）与嵌套目录划分四层：L1 营销与公开只读页、L2 认证页、L3 制作应用（`products/(app)` 挂载 `AppShell` 常驻侧栏）、L4 Playbook 组件手册；所有页面共享根 `layout.tsx` 注入的主题/Toast Provider、`globals.css` + `design-system.css` 以及 `_components/` 下的跨路由组合（`route-status`、`unwired-panel`、`new-project-dialog` 等）。API 路由集中在 `api/`，遵循「参数解析→鉴权→委托 feature 层」的单向契约，业务逻辑不在本目录实现。错误处理分层：`global-error.tsx` 兜底 root layout 失败，`not-found.tsx` 处理未匹配 URL，`products/(app)/error.tsx` 与 `not-found.tsx` 在 AppShell 内保留侧栏，四者共用 `_components/route-status.tsx`。上下文参数（如 `projectId`）强制从 URL 获取，禁止客户端全局状态推断，链接由 `features/navigation/products-routes.ts` 生成。
