- 每个路由文件顶部声明 `export const dynamic = 'force-dynamic'`，禁止静态生成以确保会话实时性。
- 受保护的 POST/PUT/DELETE 处理器统一通过 `withApiSession(async () => ...)` 包裹，GET 中按需调用 `currentSession()` 获取当前用户。
- 请求体验证使用 Zod schema 的 `safeParse`，失败时返回 `{ ok: false, error: ..., status: 400 }` 的 JSON 响应。
- 业务异常通过 `instanceof` 判断特定错误类型（如 `ProjectWorkflowStartError`、`ProjectCreateInputError`），返回包含 `code` 和 `statusCode` 的结构化响应。
- 非领域异常统一经 `classifyWorkflowError(error, { stage: 'QUEUE' })` 投影为 `{ message, code }` 后以 409 状态返回。
- 路由文件与测试文件成对命名（`route.ts` + `route.test.ts`），测试位于同目录下便于定位。
