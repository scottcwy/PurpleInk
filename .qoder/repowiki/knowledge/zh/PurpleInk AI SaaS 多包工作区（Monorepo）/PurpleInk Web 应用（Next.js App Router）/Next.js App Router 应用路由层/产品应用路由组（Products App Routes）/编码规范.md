- 每个 page.tsx 通过 withPageSession(currentPath, renderFn) 包裹服务端渲染逻辑，未登录时自动 302 重定向到指定路径
- 页面顶部声明 export const dynamic = 'force-dynamic' 强制动态渲染，避免静态生成缓存
- 复杂页面将 API 调用、状态管理、视图模型拆分到独立的 *-api.ts、*-workspace.tsx、*-view-model.ts 文件中，并与同名 *.test.ts 配对
- 通过 PublishNavContext 向子树注入 projectId 与 rendererNodeId，作为跨页面共享的发布导航上下文
- RSC 页面中使用 Promise.all 并行拉取多个投影数据（项目列表、账单、用量等），再组装成单一 view model 传给 UI 组件
