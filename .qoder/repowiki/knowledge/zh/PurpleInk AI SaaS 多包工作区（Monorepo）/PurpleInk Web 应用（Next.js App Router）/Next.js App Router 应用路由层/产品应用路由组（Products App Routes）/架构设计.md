基于 Next.js App Router 的 (app) 路由组组织，根目录 src/app/products/page.tsx 通过 permanentRedirect 统一跳转到 dashboard；(app)/layout.tsx 提供共享 AppShell 外壳与 robots:noindex 元数据，(app)/template.tsx 使用 motion/react 为右侧内容添加淡入上浮过渡动画。每个业务子路由（billing/dashboard/projects/settings/canvas/[projectId]/export/[projectId]/shots/[shotId]/）均为独立 page.tsx，统一通过 withPageSession 包装进行服务端会话校验与重定向，数据获取采用 RSC 异步函数 + Promise.all 并行拉取投影数据后传入纯 UI 组件。复杂交互页面（如 canvas、export、shots）按功能拆分为 *-api.ts、*-workspace.tsx、*-view-model.ts 等文件，并配套 *.test.ts 测试文件，形成「页面 → API/状态管理 → 视图模型 → UI 组件」的分层结构。
