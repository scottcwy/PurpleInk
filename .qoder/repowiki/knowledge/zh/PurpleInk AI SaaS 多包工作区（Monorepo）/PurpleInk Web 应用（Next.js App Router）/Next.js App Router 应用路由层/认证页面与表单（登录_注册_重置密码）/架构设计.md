模块以 Next.js App Router 的 `(auth)` route group 组织：`layout.tsx` 作为 L2 壳，左右分栏——左侧 `AuthPoster` 海报固定视口高度，右侧承载表单；每个业务页（`login/page.tsx`、`signup/page.tsx`、`password/reset/page.tsx`）仅负责元数据、已登录重定向（`redirectIfAuthenticated`）和 Suspense 包裹客户端组件。

客户端逻辑集中在 `_components/_` 下：`auth-form-shell.tsx` 提供统一的标题/描述/底部链接外壳与蜜罐字段；`login-form.tsx`、`signup-form.tsx`、`reset-password-form.tsx` 各自封装表单状态与提交；`use-verification-code.ts` 是注册与重置共用的验证码控制器（取挑战→填答案→要验证码→冷却计时），通过 `AuthRequestError.retryAfterSeconds` 与服务端 429 对齐。

所有认证 POST 请求统一走 `_components/auth-api.ts` 的 `postJson` 封装，只暴露 `login`、`signup`、`resetPassword`、`requestVerificationCode`、`fetchHumanCheckChallenge` 五个函数，服务端错误一律归一化为 `AuthRequestError`，前端不区分具体失败原因，只展示统一文案。依赖方向单向：page → form component → auth-api → `/api/auth/*`。
