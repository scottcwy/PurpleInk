- 所有认证表单共用 `AuthFormShell` 作为右栏容器，标题、描述、底部链接通过 props 注入，避免复制布局代码。
- 需要验证码的流程统一通过 `useVerificationCode('signup'|'password_reset')` Hook 管理人机挑战、蜜罐、倒计时与发送状态，注册与重置两条路径共享同一控制器。
- 所有认证 POST 请求必须经过 `auth-api.ts` 的封装函数，服务端错误统一抛出 `AuthRequestError`，前端只读取 `message` 字段展示给用户，不自行解析 HTTP 状态码。
- 页面组件采用异步 Server Component 模式：导出 `metadata` 常量、调用 `redirectIfAuthenticated` 做服务端跳转、用 `<Suspense fallback={null}>` 包裹客户端表单组件。
- 表单提交使用 `router.replace(redirectTo)` 而非 `push`，确保登录/注册成功后返回栈中不留登录页。
- 蜜罐字段通过 `HoneypotField` 渲染为不可见且不可聚焦的隐藏输入，使用 `aria-hidden` + `tabIndex={-1}` + 绝对定位移出视口，而非 `display:none`。
