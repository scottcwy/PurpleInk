- 路由组使用圆括号命名（如 `(marketing)`、`(auth)`）表示不映射到 URL，仅用于共用 layout 分组
- 私有目录以下划线开头（`_components`、`_components/auth-api.ts`），Next.js 自动跳过路由解析
- API 路由统一返回固定语义状态码：400 参数非法、404 不存在或不属于当前作用域、409 状态冲突、422 外部凭据校验失败
- 除 `/api/ping` 外全部标记 `dynamic = 'force-dynamic'`，业务逻辑委托 `src/features/*` 实现
- 错误与未找到页面共用 `_components/route-status.tsx`，只展示错误类别与 `error.digest`，不回显 message、堆栈或 provider 原始响应
