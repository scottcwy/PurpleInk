- 所有路由统一设置 `export const dynamic = 'force-dynamic'` 以禁用静态渲染。
- 通过 `withApiSession` 高阶函数注入会话对象 `{ userId, workspaceId }`，业务逻辑不直接读取 session。
- 领域服务返回或抛出的错误统一携带 `code` 字段，路由层将其映射为明确的 HTTP 状态码与中文 `error` 消息，禁止向客户端泄露原始错误细节。
- 输入校验集中在独立函数中完成（如 `readCode`、`validIdempotencyKey`），失败时直接返回 400 且不调用下游服务。
- 测试使用 `vi.hoisted` 声明 mock 对象并通过 `vi.mock` 替换真实依赖，同时在 `beforeEach` 中清理 mock 状态。
