- 每个 route.ts 顶部声明 `export const dynamic = 'force-dynamic'`，确保端点不被静态预渲染。
- 请求体统一通过 `readJsonBody(request)` 读取后使用 Zod schema（如 `loginSchema`、`signupSchema`、`requestVerificationCodeSchema`）的 `safeParse` 校验，失败时返回 `authFailureResponse(authFailure(...))`。
- 成功登录后统一调用 `attachSessionCookie(response, token, expiresAt)` 写入会话 Cookie，失败路径一律返回统一的 `authFailureResponse`。
- 涉及枚举安全的端点（登录、注册验证码、密码重置验证码）对未找到账号/邮箱的情况返回相同状态码与文案，避免信息泄露。
- 需要防缓存的 GET 端点（session、human-check）显式设置 `{ headers: { 'Cache-Control': 'no-store' } }`。
- 请求指纹通过 `requestFingerprint(request)` 注入到业务调用中，用于速率限制与审计。
