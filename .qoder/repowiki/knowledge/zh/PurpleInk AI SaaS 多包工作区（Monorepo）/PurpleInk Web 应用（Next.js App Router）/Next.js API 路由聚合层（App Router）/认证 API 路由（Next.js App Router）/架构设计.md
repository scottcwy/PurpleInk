每个子目录对应一个 RESTful 端点（login、signup、logout、session、human-check、password/code、password/reset、signup/code），采用 Next.js App Router 约定：目录内 `route.ts` 导出 `GET/POST` 函数作为请求处理器。所有路由统一声明 `export const dynamic = 'force-dynamic'` 避免静态生成。路由层仅做请求解析、参数校验与响应组装，业务逻辑委托给 `@/features/auth/*` 下的服务模块（account-service、verification-service、session、api-session、human-check-service），安全细节（会话 cookie 签发/清除、请求指纹、错误封装）由 `@/lib/auth/session-cookie` 与 `@/features/auth/http` 提供。依赖方向严格单向：route → features → lib，不反向依赖。
