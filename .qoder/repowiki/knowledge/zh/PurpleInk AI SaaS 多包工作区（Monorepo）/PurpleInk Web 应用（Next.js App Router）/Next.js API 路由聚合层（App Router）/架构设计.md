所有端点均位于 src/app/api/ 下，遵循 Next.js App Router 的文件路由约定：每个 route.ts 暴露 GET/POST 等函数式处理器。跨域共享的鉴权模式为：除 auth/session 直接调用 currentSession() 外，其余受保护路由统一通过 withApiSession 包装器注入 session 或 userId，再委派给 @/features/* 中的领域函数（如 getBillingProjection、getAiUsageProjection、projects CRUD 等）。SSE 流式接口（director/stream）在 route 中建立连接后直接写入流，不经过传统 JSON 响应。测试文件与实现文件同名 .test.ts 并列放置，便于单文件定位。
