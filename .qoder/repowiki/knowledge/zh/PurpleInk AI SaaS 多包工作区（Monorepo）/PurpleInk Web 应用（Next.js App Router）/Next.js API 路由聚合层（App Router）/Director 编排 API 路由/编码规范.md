- 所有 HTTP handler 均通过 `withApiSession(() => ...)` 包裹，确保请求体解析与业务逻辑运行在已认证的会话上下文中。
- 请求体参数统一用 Zod `z.object(...).strict()` 定义 schema，并在 `parseRequest` 或内联 `safeParse` 后返回 `{ success, response }` 或解构后的 typed data。
- 错误处理采用分层策略：先捕获领域异常（如 `ProjectWorkflowStartError`、`QuotaExhaustedError`、`SkipRejectedError`）返回带 `code` 的结构化 JSON，其余异常经 `classifyWorkflowError({ stage: 'QUEUE' })` 投影为统一格式。
- SSE 端点使用 `new ReadableStream` + `TextEncoder` 手动构造 `event: xxx\ndata: ...\n\n` 帧，并通过 `KEEPALIVE_MS` 定时器发送 `: keepalive` 心跳，同时在 `request.signal.abort` 时清理订阅与定时器。
- SSE 回调中的异步操作通过 `runInAuthContext(authContext, fn)` 重新绑定认证上下文，避免 `withApiSession` 的作用域无法覆盖流回调的问题。
