模块遵循 Next.js App Router 的 `src/app/api/<route>/route.ts` 约定，每个子目录对应一个 API 端点：
- `/api/render/route.ts`：POST 入口，接收 `{projectId, nodeId, intent}` 并通过 `withApiSession` 鉴权后调用 `executeNodeAction` 入队执行。
- `/api/render/export/route.ts`：GET 查询导出就绪状态（含 QA 检测与 artifact 下载链接），POST 触发终片导出并处理降级确认与阻塞分支。
- `/api/render/thumbnails/route.ts`：GET 按固定时间点生成 8 帧缩略图，仅返回 artifact URL 而不暴露底层 key。

所有路由共享模式：声明 `dynamic = 'force-dynamic'`、使用 Zod 校验请求体/参数、通过 `withApiSession` 包裹业务逻辑、调用 `initQueue()` 确保队列可用、错误统一以 `{ok, error, code?}` 结构 + HTTP 状态码返回。业务层依赖方向单向指向 `@/features/*`（director、render、auth、projects）和 `@/lib/queue`，路由层不持有领域逻辑。
