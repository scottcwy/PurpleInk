- 每个路由文件顶部声明 `export const dynamic = 'force-dynamic'` 以禁用静态生成。
- 请求数据一律通过 Zod schema 的 `safeParse` 校验，失败时返回 400 与中文错误消息。
- 所有路由处理器通过 `withApiSession(() => handler())` 包裹，将鉴权与会话注入与业务逻辑解耦。
- 错误响应统一采用 `{ ok: false, error, code? }` 结构，并根据语义选择 400/404/409 等状态码。
- 需要异步队列的路由在入口处显式调用 `await initQueue()` 以确保队列已初始化。
- 项目兼容性校验通过 `assertProjectWorkflowSupported(projectId)` 在业务逻辑前统一拦截。
