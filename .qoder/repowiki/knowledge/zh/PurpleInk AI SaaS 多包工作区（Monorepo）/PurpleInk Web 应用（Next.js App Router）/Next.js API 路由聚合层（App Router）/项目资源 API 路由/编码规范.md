- 所有路由函数统一通过 `withApiSession(() => handler(...))` 包裹，确保鉴权逻辑集中处理。
- 动态路由参数通过 `Promise<{ id: string }>` 形式在函数签名中声明，并在 handler 内部 `await params` 获取。
- 输入参数使用 Zod 进行安全校验（如 UUID 验证），失败时返回 `{ ok: false, code, error }` 结构的 JSON 响应。
- 领域异常按类型分支映射为 HTTP 响应，未知异常记录 `console.error` 后返回脱敏消息与 500/503 状态码。
- 响应体统一遵循 `{ ok: boolean, ...payload }` 模式，成功时附带业务数据，失败时附带 `code` 和 `error` 字段。
