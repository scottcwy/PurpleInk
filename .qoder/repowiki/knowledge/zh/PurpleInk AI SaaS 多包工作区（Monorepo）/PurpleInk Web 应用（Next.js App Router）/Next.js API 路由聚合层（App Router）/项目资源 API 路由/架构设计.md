基于 Next.js App Router 的动态路由结构：`projects/route.ts` 提供项目列表（GET）与创建（POST），`projects/[id]/route.ts` 提供重命名/导出设置更新（PATCH）与删除（DELETE），`[id]/start/route.ts` 负责启动/停止工作流执行，`[id]/execution/route.ts` 仅返回执行快照。所有路由均通过 `withApiSession` 包装实现会话鉴权，HTTP 层只做参数解析、错误映射与响应封装，业务调用全部委派给 `@/features/projects`、`@/features/canvas`、`@/features/billing` 等 feature 模块，依赖方向单向向下，不反向依赖上层。每个路由文件声明 `export const dynamic = 'force-dynamic'` 禁用静态生成。
