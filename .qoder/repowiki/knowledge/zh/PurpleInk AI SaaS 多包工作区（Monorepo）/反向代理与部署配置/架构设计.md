模块由三部分组成：
- `deploy/reverse-proxy/`：Caddy 反向代理的容器化部署。`Dockerfile` 以 `caddy:2.10-alpine` 为基础镜像，复制 `Caddyfile` 和 `entrypoint.sh`；`entrypoint.sh` 作为容器入口，从 Docker Compose secrets（`/run/secrets/basic_auth_credentials`）中解析用户名与 bcrypt 哈希并注入 `CVC_BASIC_AUTH_USER` / `CVC_BASIC_AUTH_HASH` 环境变量，拒绝无凭据启动，再 `exec caddy run`。
- `config/tts.env.example`：TTS 提供商（ListenHub FlowSpeech）的配置模板，真实密钥应放在 `.env.local`。
- `.claude/settings.json`：Claude Code 权限白名单，允许执行 `pnpm lint *`。
依赖方向单向向外：入口脚本依赖 Docker secrets 机制，Caddyfile 通过环境变量驱动配置，不直接耦合应用代码。
