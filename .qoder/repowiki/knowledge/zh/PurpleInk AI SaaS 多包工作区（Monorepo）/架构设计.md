根目录作为 pnpm workspace 根（pnpm-workspace.yaml），聚合 web_app（Next.js App Router）、server_service（Node HTTP API + AI 采集/视频编排）、procedural_sfx_lib（@purpleink/procedural-sfx）、scripts_and_tools、tests、docs、deploy_infra 等子模块。
- 前端通过 next.config.ts 的 rewrites 将所有 /api/* 请求反向代理到 BACKEND_ORIGIN（默认 http://localhost:8787）指向 server_service，实现浏览器同源访问、生产环境单域名部署且 worker 不对外暴露。
- @purpleink/procedural-sfx 以 workspace:* 依赖被 web_app 引用，提供运行时无外部音频依赖的 WAVE 音效合成。
- drizzle.config.ts、vitest.config.ts、vitest.pg.config.ts、eslint.config.mjs、tsconfig.json 等根级配置文件为所有子包提供统一的类型检查、测试、数据库迁移与代码规范。
- scripts_and_tools 中的 dev/start-dev.ps1 通过 pnpm 脚本串联 dev/dev:worker/dev:all 启动 Web、Server、Postgres，构成一键开发流程；verify/* 脚本执行架构基线与端到端冒烟验证。
- deploy_infra 提供 Caddy 反向代理 Docker 镜像，配合 docker-compose.dev.yml / docker-compose.prod.yml 完成本地与生产编排。
