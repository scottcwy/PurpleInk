模块以 `src/index.ts` 为公共 API 入口，导出类型、常量与跨层验证器 `isProceduralSfxResultContract`；`plan.ts` 负责将帧边界序列规约为最多 24 个 cue 的计划（含 timingHash 与 cuePlanHash），依赖 `hash.ts` 中的纯 JS SHA-256 实现；`wav.ts` 基于同一套种子算法（FNV-like `seedFromString`）按 preset 合成 48kHz 单声道 16bit WAV 字节流，并提供 `readWavInfo` 做契约校验；`hash.ts` 同时提供 `sha256Hex` 与 `seedFromString`，被 plan 与 wav 共同依赖，形成单向依赖链 index ← plan/wav ← hash。所有输入均通过运行时断言与类型守卫进行 fail-closed 校验，确保浏览器端无需原生音频库即可生成确定性音效。
