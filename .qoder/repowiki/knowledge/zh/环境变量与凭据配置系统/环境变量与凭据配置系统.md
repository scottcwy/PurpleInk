PurpleInk 采用双进程、各自为政的环境变量加数据库加密凭据混合配置体系，Next.js 前端应用与独立 Node.js 渲染 Worker 拥有完全隔离的 .env 文件与变量命名空间，平台托管 AI 凭据通过 CVC_MANAGED_* 环境变量注入，自定义 BYOK 凭据则经主密钥加密后持久化到 PostgreSQL。

## 配置文件分层与加载顺序
- Next 进程：根目录 .env.example 定义 Next 直接消费的变量（如 DATABASE_URL、CVC_MANAGED_*、BACKEND_ORIGIN、NEXT_PUBLIC_API_BASE、邮件 SMTP 等），真实值写入被 Git 忽略的 .env.local。Next 脚本通过 @next/env 的 loadEnvConfig(process.cwd()) 加载。
- Worker 进程：server/.env.example 定义 worker 专用变量（STEP_API_KEY、IMAP_*、TTS_PROVIDER、GEMINI_API_KEY、SMTP_* 等），启动时由 server/src/lib/load-env.ts 依次加载 server/.env 到仓库根 .env.local（后者可覆盖同名键）。该 loader 是极简实现，不依赖第三方 dotenv 库，仅解析 KEY=VALUE 行并跳过注释。
- TTS 独立模板：config/tts.env.example 单独列出 ListenHub TTS 的配置项，与 worker 的 TTS 配置对齐但不混入根 .env.example。

## 凭据存储与运行时解析
- 平台托管 Key：StepFun、MiMo、Gemini 三家内置服务的 API Key 仅从 CVC_MANAGED_STEPFUN_API_KEY、CVC_MANAGED_MIMO_API_KEY、CVC_MANAGED_GEMINI_API_KEY 读取，由 src/features/ai/managed-credentials.ts 唯一解析，不得回退到旧的 provider env 名称或 workspace 凭据。
- 自定义 BYOK 凭据：OpenAI-compatible 自定义端点的 apiKey 经 scripts/setup/bootstrap-credentials.ts 验证后加密保存到 provider_credentials 表，由 PostgresProviderCredentialStore 管理；模型、端点等非敏感配置保存在 workspace_settings.ai.openai-compatible。
- 主密钥机制：CVC_CREDENTIAL_MASTER_KEY（32 字节 canonical base64）用于加密所有 provider credentials，缺失即抛错无明文 fallback，通过 scripts/migration/provision-master-key.ts 生成。

## 配置来源优先级与约束
- Next 侧：托管目录加 CVC_MANAGED_* 大于 DB 加密凭据（仅自定义 OpenAI-compatible）大于代码默认值。
- Worker 侧：server/.env 大于仓库根 .env.local（覆盖同名键）大于代码默认值。
- 安全约束（AGENTS.md §7 及文档强制）：secret 类变量值必须留空于示例文件；禁止携带 secret 的 NEXT_PUBLIC_*；任何一项 SMTP 配置缺失即视为通道未配置，API 返回 503 而非静默失败。

## 关键文件与模块
- server/src/lib/load-env.ts：worker 的极简 .env 加载器
- server/src/index.ts：worker 入口，启动时按顺序加载两个 .env 文件
- src/features/ai/config.ts：StepFun 配置解析，区分 env/default/source 三元组
- src/features/ai/managed-credentials.ts：平台托管 Key 的唯一解析器
- docs/configuration/credentials.md：凭据边界与 truth hierarchy 的权威文档
- docs/configuration/tts.md：TTS/ASR 配置协议与校验流程
- .env.example / server/.env.example / config/tts.env.example：各进程环境模板

## 架构约定
- 禁止引入统一的 env loader 或共享配置文件，Next 与 worker 的 stores 保持分离（tests/env.test.ts:21-32 强制执行）。
- 示例环境文件只能列空变量名，不得包含任何真实平台 Key。
- 设置页通过 POST /api/settings 更新 DB 中的加密凭据，GET 接口绝不返回 apiKey，仅返回 value/source 元数据。
- TTS 与 ASR 的自定义端点与文本视觉端点互不共享凭据、端点或模型，各自独立 profile 存储。
