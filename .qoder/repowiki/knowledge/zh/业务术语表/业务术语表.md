### 工作流第一步
- 定义：PurpleInk 营销出片工作流的第一个节点，即 INGEST 阶段，对应 script-import 节点。负责导入脚本内容并展开镜头结构，是整个工作流的入口节点。
- 别名：INGEST、script-import、入口节点

### 模式 F
- 定义：dev server 持有旧模块导致的失败模式。当修改 queue handler、stage runner、模型路由等被 initQueue 持有的模块后，长驻的 next dev 进程不会自动 HMR 替换旧模块实例，导致重试仍报同一个旧错误。解决方案是重启 pnpm dev 进程。
- 别名：dev server 持有旧模块

### task_attempts
- 定义：记录工作流各阶段执行尝试的数据库表，包含 failure.message 原始报文、attempt 时长、started_at 和 completed_at 等字段。用于诊断节点失败原因和执行状态。
- 别名：任务尝试、执行尝试

### provider_credentials
- 定义：存储 AI 提供商凭据的数据库表，采用加密存储方式。Next 应用侧只从 DB 读取凭据，不支持 env fallback；worker 侧仅从环境变量读取。bootstrap-credentials.ts 脚本用于初始化凭据。
- 别名：提供商凭据、API密钥存储

### workspace_settings
- 定义：存储工作区设置配置的数据库表，包含 ai.openai-compatible 等配置项。schemaVersion: 2 的 profile-store 解析器与旧模块不兼容会导致问题。
- 别名：工作区设置、配置存储

### StatusPill
- 定义：设计系统中的状态指示组件，用于显示节点状态（如 generating、running、failed 等）。支持 animate-pulse 脉冲动画效果，符合"状态不能只靠颜色表达"的规范。
- 别名：状态徽章、状态指示器

### SettingsPanel
- 定义：设置页面的主面板组件，支持折叠/展开状态管理。默认所有折叠栏处于折叠状态，支持受控 prop 模式和 scrollIntoView 定位功能。
- 别名：设置面板

### SectionNav
- 定义：设置页面右侧的业务导航组件，采用微线条质感设计。选中状态显示底部微下划线而非左侧高亮，点击后有下划线微展开动画和被选中部分微发光效果。
- 别名：分段导航、业务导航

### OpenAI兼容模型服务
- 定义：设置页面中的一个配置板块，允许用户注册自定义的 OpenAI 兼容文本/视觉模型。包含 endpoint 配置、模型选择、API Key 验证等功能，状态显示为"已配置"。
- 别名：OpenAI兼容、自定义模型

### ProviderDetail
- 定义：模型供应商详情面板组件，显示选中的模型供应商的详细配置信息。支持保存反馈逻辑、scrollIntoView 定位等功能。
- 别名：供应商详情、模型详情

### ModelServicePanels
- 定义：模型服务面板集合组件，统一管理不同模型服务的配置界面。需要传递必填 props 包括 ProviderDetail 等子组件所需的参数。
- 别名：模型服务面板

### TextField
- 定义：设计系统中的文本输入组件，支持 default variant 和其他变体。在 settings-form 横幅区域中使用，具有柔和的圆角光晕效果和一致的表单圆角样式。
- 别名：文本框、输入框

### SettingsRow
- 定义：设置行组件，用于展示设置项的标签和输入控件。支持 chevron prop 控制是否显示箭头图标，用于区分可点击进入新页面的板块。
- 别名：设置行

### playbook
- 定义：组件登记与展示页面，位于 /playbook/* 路由下。作为设计系统的 SSOT（单一真实来源），所有 UI 组件必须在此登记，页面不得本地拼装平行的 UI 组件。
- 别名：组件手册、设计系统

### CVC
- 定义：CodeVideoCanvas 的缩写，是 PurpleInk 的前身或过渡应用。/legacy/* 路由下的 CVC 过渡域不等于新的 Product/Release 域模型，是独立的功能模块。
- 别名：代码视频画布、CodeVideoCanvas

### Stage A
- 定义：PurpleInk 项目的当前阶段，将营销出片链路、CodeVideoCanvas 过渡应用、组件 Playbook 和新 Product/Release 路由骨架合并在一个 Next.js 仓库中。Stage B 的路由壳尚未接线。
- 别名：第一阶段、A阶段
