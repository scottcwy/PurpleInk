## 系统概述

PurpleInk 采用**基于 .env 文件的环境变量分层加载机制**，将 Next.js 前端、独立 Node.js 后端 worker、TTS 子系统和脚本工具的配置解耦，通过 `process.env` 作为唯一运行时配置源，不依赖第三方配置库。

## 核心架构与约定

### 1. 多进程 .env 隔离
- **Next 进程**：根目录 `.env.example` + `.env.local`（git ignore），仅包含 Next 直接消费的变量
- **Server Worker**：`server/.env.example` + `server/.env`（git ignore），worker 启动时按顺序加载 `server/.env` → 仓库根 `.env.local`（后者可覆盖同名键）
- **TTS 配置**：`config/tts.env.example`，独立于上述两份模板
- 三份模板互不交叉，各自为政，由 `docs/configuration/credentials.md` 文档约束

### 2. 加载机制
- **后端入口** (`server/src/index.ts`)：启动时调用自定义 `loadEnv()` 函数，依次加载 `server/.env` 和根 `.env.local`
- **loadEnv 实现** (`server/src/lib/load-env.ts`)：极简解析器，支持注释、引号包裹值、已存在键不覆盖的语义
- **Next 构建/脚本**：通过 `@next/env` 的 `loadEnvConfig(process.cwd())` 加载根 `.env*` 文件
- **Node 原生**：`process.env` 直接读取，无中间层封装

### 3. 配置分层策略
每个 AI Provider（StepFun/Gemini/MiMo）遵循统一模式：
- **默认值**：代码内硬编码 `DEFAULTS` 对象
- **环境变量覆盖**：通过 `ENV_KEYS` 映射到 `process.env[KEY]`
- **优先级**：`process.env > DEFAULTS`，且 baseUrl 字段支持空值回退
- **API Key 来源**：托管模式从 `CVC_MANAGED_*_API_KEY` 环境变量或数据库凭据存储读取；BYOK 模式从用户设置的凭据存储读取

### 4. 安全约束
- 所有 secret 类变量（API key / master key / 口令）在模板文件中值必须留空
- 真实值只写入被 git 忽略的 `.env.local` 或 `server/.env`
- 禁止携带 secret 的 `NEXT_PUBLIC_*` 变量
- 凭据加密主密钥 `CVC_CREDENTIAL_MASTER_KEY` 缺失即抛错，无明文 fallback

### 5. 运行时配置访问模式
- **Next Config**：`next.config.ts` 中直接读取 `process.env.BACKEND_ORIGIN` 等变量
- **Feature 模块**：各 provider config 文件暴露 `get*Config()` 和 `describe*Config()` 函数，返回带 source 标记的配置视图
- **服务启动**：端口、代理路径等基础设施配置通过环境变量注入

## 关键文件
- `.env.example` - Next 进程环境变量模板
- `server/.env.example` - Worker 进程环境变量模板
- `config/tts.env.example` - TTS 子系统配置模板
- `server/src/lib/load-env.ts` - 自定义 .env 加载器
- `server/src/index.ts` - Worker 启动入口，执行 .env 加载
- `next.config.ts` - Next 配置，消费 BACKEND_ORIGIN 等环境变量
- `src/features/ai/config.ts` - AI 配置核心逻辑，定义 Provider 配置解析模式
- `src/features/ai/gemini-config.ts` - Gemini 配置实现
- `src/features/ai/mimo-config.ts` - MiMo 配置实现
- `docker-compose.dev.yml` - 开发环境数据库配置

## 设计决策
- **零依赖配置库**：手写 .env 解析器，避免引入 dotenv 等外部依赖
- **进程间配置隔离**：不同进程有独立的 .env 文件，避免配置污染
- **渐进式覆盖**：`.env.local` 可覆盖模板中的占位符，支持本地开发覆盖
- **类型安全**：通过 TypeScript 接口定义配置结构，编译期验证
- **可观测性**：配置来源标记（'env' | 'default' | 'settings'）便于调试和审计
