## 简介
本文件面向邮件服务的集成与使用，覆盖以下方面：
- 邮件服务提供商集成配置（SMTP、API 密钥、连接池）
- 邮件模板系统（模板引擎、变量替换、多语言支持、品牌化设计）
- 邮件发送队列（任务调度、重试机制、失败处理）
- 邮件内容生成与管理（HTML 模板、纯文本降级、附件处理）
- 监控与日志（发送状态、错误追踪、性能指标）
- 开发预览工具与测试覆盖
- 扩展指南与故障排除

说明：本项目包含两类邮件相关能力——IMAP 邮件采集（用于从邮箱拉取数据）与认证流程中的邮件发送（用于验证码、重置密码等）。本文重点围绕"邮件发送"进行系统化文档化，同时简要说明 IMAP 采集的边界。

## 核心组件
- 邮件发送封装（mailer.ts）
  - 负责选择并调用底层邮件提供商（如 SMTP 或 API），统一发送接口
  - 管理凭据加载、连接参数、重试与错误分类
- 邮件模板系统（mail-templates.ts）
  - 提供模板解析与变量替换，支持 HTML 与纯文本双版本
  - 集成品牌化色彩系统（靛蓝渐变 #333da7/#6366f1/#a5b4fc）
  - 支持明暗模式自适应主题
  - 可结合多语言键值映射进行本地化
- 失败处理（mail-failure.ts）
  - 对网络错误、认证失败、限流等进行分类与重试策略
- 开发预览工具（mail-preview.ts）
  - 提供邮件模板的本地预览和调试功能
  - 支持实时查看模板渲染效果
- 作业运行器与存储（job-runner.ts, job-store.ts）
  - 将邮件发送作为作业入队、调度、执行与记录结果
- IMAP 邮件采集（imap-email.ts）
  - 通过 IMAP 协议读取邮件，用于业务数据采集（非发送）

## 架构总览
邮件发送的整体流程如下：
- 业务触发（例如用户注册、密码重置）
- 构建邮件作业（收件人、模板、变量、附件）
- 入队与调度（作业运行器）
- 模板渲染（HTML + 纯文本降级，应用品牌化样式）
- 选择提供商并发送（SMTP/API）
- 记录结果与错误（成功/失败/重试）

## 详细组件分析

### 邮件发送封装（mailer.ts）
- 职责
  - 统一对外暴露 send() 接口，屏蔽不同提供商差异
  - 管理凭据（SMTP 主机、端口、用户名、密码；或 API 密钥）
  - 控制连接参数（超时、TLS/SSL、连接池大小）
  - 错误分类与重试决策（网络异常、认证失败、限流）
- 关键行为
  - 根据配置选择 SMTP 或 API 模式
  - 在发送前校验必要字段（收件人、主题、正文）
  - 记录发送耗时与状态码，便于监控
- 扩展点
  - 新增提供商时，实现统一接口并注入到选择器

### 邮件模板系统（mail-templates.ts）
- 职责
  - 维护模板集合（HTML 与纯文本）
  - 变量替换（姓名、链接、验证码等）

- 最佳实践
  - 保持 HTML 与纯文本同步更新
  - 敏感信息不放入模板变量（避免泄露）
  - 遵循品牌设计规范确保视觉一致性

## 开发预览工具

### 工具概述
邮件模板开发预览工具是一个专门用于调试和验证邮件模板的工具，位于 `scripts/dev/mail-preview.ts`。它提供了完整的开发环境，支持实时预览、变量注入和样式验证。

### 主要功能
- **模板渲染预览**：实时显示邮件模板的最终渲染效果
- **变量注入测试**：支持各种变量类型的测试和验证
- **品牌化样式检查**：自动验证靛蓝渐变色彩系统的应用
- **明暗模式主题切换**：支持在不同主题模式下预览邮件效果
- **嵌入式Logo验证**：验证项目Logo的正确显示
- **响应式布局验证**：在不同屏幕尺寸下预览邮件布局
- **错误调试**：提供详细的错误信息和调试输出

### 使用方法
```bash
# 启动开发预览工具
npm run mail-preview

# 指定特定模板进行预览
npm run mail-preview -- --template=verification-code

# 启用调试模式
npm run mail-preview -- --debug
```

### 支持的模板类型
- 验证码邮件模板（已重新设计视觉样式）
- 密码重置邮件模板
- 欢迎邮件模板
- 营销邮件模板

**更新** 开发预览工具现已支持明暗模式主题切换预览和嵌入式Logo显示验证，为验证码邮件等新设计的模板提供了更好的调试体验。

## 性能考虑
- 连接池
  - SMTP 连接复用与池化，减少握手开销
  - 合理设置最大连接数与空闲超时
- 并发与背压
  - 限制并发发送数量，避免被提供商限流
  - 使用队列缓冲突发流量
- 模板渲染
  - 预编译常用模板，减少运行时开销
  - 缓存静态资源（Logo、样式）
  - 优化品牌化样式的应用效率
  - 明暗模式主题切换的性能优化
- I/O 优化
  - 批量发送时合并附件与压缩
  - 异步处理大附件上传与下载
- 开发预览优化
  - 增量渲染避免全量重绘
  - 内存管理和垃圾回收优化

## 故障排除指南
- 常见问题
  - 认证失败：检查 SMTP 用户名/密码或 API 密钥是否正确
  - 连接超时：确认防火墙与端口开放，检查 TLS/SSL 配置
  - 限流与封禁：降低并发，启用指数退避重试
  - 模板渲染错误：确保所有变量已填充，HTML 合法
  - 品牌化样式问题：检查 CSS 变量和颜色定义是否正确
  - 明暗模式显示异常：检查主题切换逻辑和CSS媒体查询
  - Logo显示问题：验证嵌入式Logo的路径和格式
- 排查步骤
  - 查看作业状态与错误日志
  - 使用开发预览工具验证模板渲染
  - 复现实验环境，最小化输入验证
  - 逐步禁用功能定位问题（关闭附件、简化模板）
  - 检查明暗模式下的样式兼容性
- 恢复策略
  - 自动重试与死信队列
  - 人工介入与告警通知
  - 模板回滚和版本管理

**更新** 新增了明暗模式主题问题和嵌入式Logo显示的故障排除方法。
