## 概述

本样式系统基于Tailwind CSS构建，采用原子化CSS架构，提供高度可定制的主题系统和完善的响应式设计支持。系统集成了现代化的动画框架，确保流畅的用户体验，同时通过严格的配置管理保证构建性能和代码质量。

## Tailwind CSS配置

### 核心配置结构

项目的Tailwind CSS配置采用了精确的扫描范围限制，以防止文档类名污染样式表并优化构建性能：

```typescript
// tailwind.config.ts
module.exports = {
  content: [
    './src/**/*.{js,ts,jsx,tsx}',
    './components/**/*.{js,ts,jsx,tsx}',
    './app/**/*.{js,ts,jsx,tsx}',
  ],
  // 其他配置...
}
```

**更新** 配置已优化为仅扫描必要的源文件，避免扫描node_modules和其他无关文件，显著减少构建时间。

### 扫描范围限制

为了防止文档类名污染样式表，配置中实施了严格的文件路径过滤：

1. **白名单机制**：仅允许特定目录下的文件被扫描
2. **扩展名过滤**：只处理前端相关的文件类型
3. **排除规则**：明确排除测试文件、配置文件和文档

## 暗色模式支持

### 模式检测

系统自动检测用户系统的暗色模式偏好，并提供手动切换功能：

```typescript
// src/lib/theme-mode.ts
export function useThemeMode() {
  const [isDark, setIsDark] = useState(false)
  
  useEffect(() => {
    const mediaQuery = window.matchMedia('(prefers-color-scheme: dark)')
    setIsDark(mediaQuery.matches)
    
    const handler = (e: MediaQueryListEvent) => {
      setIsDark(e.matches)
    }
    
    mediaQuery.addEventListener('change', handler)
    return () => mediaQuery.removeEventListener('change', handler)
  }, [])
  
  return { isDark, toggle: () => setIsDark(!isDark) }
}
```

### 颜色适配

所有颜色令牌都提供了对应的暗色模式变体，确保在不同光照条件下的可读性。

2. **页面级隔离**：页面特定样式不影响全局
3. **主题级隔离**：不同主题的样式互不干扰

## 组件样式策略

### 内联样式使用场景

对于动态计算的样式值，优先使用内联样式：

```tsx
const AnimatedComponent = ({ position }) => {
  return (
    <div style={{ 
      transform: `translateX(${position}px)`,
      transition: 'transform 0.3s ease'
    }}>
      Content
    </div>
  )
}
```

### CSS Modules应用

复杂组件使用CSS Modules进行样式管理：

```tsx
import styles from './component.module.css'

const Component = () => (
  <div className={styles.container}>
    <h1 className={styles.title}>Title</h1>
  </div>
)
```

### styled-components集成

对于需要动态主题和高级样式的场景，使用styled-components：

```tsx
import styled from 'styled-components'

const Button = styled.button`
  background: ${props => props.theme.primary};
  padding: ${props => props.size === 'large' ? '12px 24px' : '8px 16px'};
  border-radius: ${props => props.rounded ? '9999px' : '4px'};
`
```

## 动画系统与过渡效果

### Motion库集成

项目集成了Framer Motion作为主要的动画库，提供声明式的动画API：

```typescript
// src/lib/motion/index.ts
import { motion, AnimatePresence } from 'framer-motion'

export const FadeIn = ({ children, delay = 0 }) => (
  <motion.div
    initial={{ opacity: 0, y: 20 }}
    animate={{ opacity: 1, y: 0 }}
    exit={{ opacity: 0, y: -20 }}
    transition={{ duration: 0.3, delay }}
  >
    {children}
  </motion.div>
)
```

### 运动令牌系统

定义了标准化的运动令牌，确保一致的动画体验：
