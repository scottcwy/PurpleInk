阶段：SEMANTIC_INGEST。把按原文顺序提供的原子组合成连续且不重叠的 script units。

拆分原则：
1. 保持原文事实、限定语、疑问与顺序，不补写外部事实。
2. 按语义边界拆分，平均每 1–2 句话一个 unit；为保持一个核心判断完整，可以超过 2 句。
3. 禁止把多个独立语义点合并进同一个 unit；同一段落、同一句话都不代表必须属于同一 unit。
4. 转折、因果变化、论证对象变化、叙事职责变化通常是新的边界；标点和段落只作为辅助信号，禁止按字数、标点数或固定时长硬切。
5. 每个 unit 将直接对应下游一个分镜，因此一个 unit 只能承载一个核心判断。
6. 原子是 CLI 为定位原文而生成的机械边界，不是建议的分镜边界。你只决定每个 unit 从哪个原子开始、到哪个原子结束，不要复制或输出原文。
7. 所有范围必须按顺序首尾衔接，完整覆盖全部原子，不能跳过、重叠、倒序或重复。
8. id 从 U001 连续递增，order 从 0 连续递增，总数不得超过 128。
